## 遗留 / 已知项

- **omp 现场未验**：本机无 omp pane；omp 静默拒绝（kind=path 过 discovery 闸门、reader 层拒绝、不产生 discovery warn）机制由单测覆盖。
- **`agents.grok_home` 遗留列**：恒写 `null`、无读取方；删列需 drizzle migration，本批不做（承 `bd97dd2`）。
- **负缓存作用域**：`DISCOVERY_RETRY_AFTER_FAILURE_MS=60s` 只降频后台常规刷新；`agent.get` / `agent.read` 与 `forceRefresh:true`（`forceDiscovery`）恒绕过（承 `bd97dd2`）。
- **显式读取不复用持久 ref**：`preferredHistoryRef` 已删，显式读取不回退持久 ref（承 `bd97dd2`）。
- **既有「源消失 ⇒ 每轮强制」**：既有行为，本批未改。
- **TOCTOU 残余**：官方会话值在上报与读取间可能失效（file-safety 闸门、文件消失/被改写）⇒ 诚实失败返回空 + 一次 warn（或 reader 层静默），可立即重试。
- **npm automation-token 限制（`npm profile get` E403）**：文档明示的永久限制，已在 0.13.2 / 0.13.3 / 0.13.4 记录（见 `.agents/notes/20261002-release-0.13.4.md`），本批**不重复登记**；本轮 `npm profile get` 复核仍为 E403（`PROFILE_GET_EXIT=1`，`2026-10-04T01_42_35_350Z-debug-0.log`）。账号姿态页面级检查（verified email / write 2FA）按 0.13.4 记录由用户决定不做、属软时点；写权限本轮被真实行使（两包 `npm publish` 均 exit 0、无 E403）。
