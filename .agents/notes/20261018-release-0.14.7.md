- **版本判型：patch → `0.14.7`**：本批包含 `agy` 额外 HOME 会话库发现扩展、`PLAN_WAITING_HISTORY` 常量导出与字面量收敛、M2 守卫同正文不同 ref 反向回归及文档/留痕更新，无任何公共 API、CLI 命令或既有行为被移除，按 `docs/releasing.md` 判据走 patch `0.14.7`。

## 被放弃的方案（必填）

- **直接在主工作树带脏文件执行打包或发布**：放弃——违反 `docs/releasing.md` 的干净工作树前置门，且会把其它任务尚未定稿的 `packages/herdsman-pi/src/{daemon-client,index,wake}.ts` 混入构建或发布产物。
