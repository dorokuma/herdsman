- **按旧流程 `pnpm build` → `npm pack` → 装本地 tarball**：已废除（会出现「同版本号、不同字节」，版本号即部署身份）。本轮只用 registry 渠道钉版本安装。
- **把 `@dorokuma/herdsman-pi` 加进 pi 的 `packages`**：不做（会与 pi 桥构成双实例）。pi 侧修复靠桥加载仓库源码 + 新开 pane 生效。附注：全局 npm 前缀里的 `@dorokuma/herdsman-pi` 副本**并未被卸载、反而已钉版本升级**（`0.14.2` → `0.14.3`，见「pi 加载路径事实核对」）；仅把它 `npm install -g` 升级/安装到全局**本身不会**双实例，双实例风险只来自把它列入 pi 的 `packages`，而列入 `packages` 本轮仍不做。
- **回滚**：未触发（全部验收达标）。回滚是用户决定，本轮不预置。
