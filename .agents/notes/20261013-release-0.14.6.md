### 版本判型：patch → **0.14.6**（不是 0.15.0）

- **依据（`docs/releasing.md` 的判据文本）**：版本级递增只在「本批含 breaking change——使用者可感知的东西，例如被移除的公共 API、CLI 命令或行为」时走 minor；该判据的核心是**移除**，不是「行为有任何变化」。本批**没有任何使用者可依赖的能力被移除**：
  - 两条改动都是**观测面新增**——在窗口查询处各加一条 `console.warn`（守卫臂 + salvage 臂）。没有事件类型、payload 字段、CLI 表面、pi 扩展钩子被删或改签名；新增的是日志锚点，不是使用者契约。
  - 唯一的源码级「面」变化是把模块内常量 `STALE_DUPLICATE_GUARD_SCAN_LIMIT` 由 `const` 改为 `export const`（供测试引用），取值仍为 500——**新增**一个模块导出，不是移除，且是 `src/` 内部模块导出而非包对外 API。
  - 「超窗漏拦」这一既有代价本批**未修**（ITEM-109 只销「扩窗与 ref 优先判据已落地」这一半），因此也没有行为语义的改动。
- **仓库先例（同判据的历史适用）**：minor 只出现在**能力移除**轮——0.13.0（删除 `herdsman daemon start|stop|restart`）、0.14.0（收窄 agent 历史读取支持面、删除五个 reader）；纯观测新增/语义 patch 轮为 0.14.1 / 0.14.2 / 0.14.4 / 0.14.5。本批与后者同形，故 patch。
- 版本号 `0.14.6` 在发布前**不存在于 registry**（两条 `npm view` 均 E404，见下），故无版本重发冲突。
