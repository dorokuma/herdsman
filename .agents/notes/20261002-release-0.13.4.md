## 被放弃的方案（必填）

- **为规避 CDN 传播的 E404 而 republish**：放弃。文档明确重发已 staged 的版本会得到 E409，正确处置是等并重试 `npm view`。
- **负载闸门不过时硬重启**：放弃。满负载（12 核被 10+ 高 CPU worker 占满）下 `herdsman.service` 的优雅关停极易超时，可能触发 systemd 强杀（SIGKILL）而非 `exitCode: 0` 退出，正是第 5 项要核验的指标会直接失败 —— 故改为有界等待。
- **为让闸门尽快通过而 kill 掉 metapi 的 `vitest` 进程**：放弃。不触碰别的项目的测试轮。
- **放宽闸门判据（把别人的项目测试排除在判据外）**：放弃。判据原文把「正在跑的 `vitest`」列为闸门条件，本窗口不擅自放宽。
- **本版部署前复跑 `pnpm check`**：放弃。任务说明的步骤清单不含该项（发布轮已覆盖）；登记为与 `AGENTS.md` 的口径差异（见遗留 #3）。
